# 工程甘特圖：版本目標與排程約定

## 定位

個人製作服務建議書、一般報告書及簡報的期程工具。純前端，日曆天計算，本機資料保存。

## V1 已完成

多層 WBS、起訖日期輸入、工期計算、五種時間尺度、前置關係與正負 lag、CPM、JSON 備份。V1 保留手填日期，另行提示邏輯衝突。

## V2.0 已納入

- 一般活動以開始日及日曆工期輸入；完成日可反算工期。
- 前置關係及工期變更自動推算下游、上階與要徑。
- 指定開始日為不得早於的限制，可在關係視窗清除。
- 各關係提供白話說明及日期結論；整體結果同時呈現。循環拒絕且原設定保留。
- 欄位拖曳／雙擊適配，主要控制說明自動換行、增高且同步右側圖列。
- 時間軸從最早工項所在單位至最晚所在單位；保留中間空檔，提供完整年度選項。
- 零工期里程碑、可開關前置箭頭、報告預覽。
- 2 倍 PNG 下載及複製，完整表格／僅圖表兩種輸出。依目前展開工項輸出。

## 日曆日期定義

一般活動 `F = S + D - 1`，D 為正整數日曆天。所有關係為不得早於的限制，多前置取最大值。

| 關係 | 一般工項限制 |
|---|---|
| FS | S後 ≥ F前 + 1 + lag |
| SS | S後 ≥ S前 + lag |
| FF | F後 ≥ F前 + lag |
| SF | F後 ≥ S前 + lag |

「完成後開始」FS＋0 隔日開始。SS＋0 同日開始；FF＋0 同日完成，避免任意對所有關係增加一天。

里程碑 D=0、顯示 S=F，代表當日完成事件，菱形位於 F+1 的時間界線；FS 後續隔日開始。SS／FF／SF 依顯示日期計算。

CPM 使用有效葉活動及固定上階的排程起日為最早限制，前推、反推計算總浮時；累計上階不參與網圖。0 或負浮時標示紅色。日末里程碑的日期座標計算使用當日邊界跨度，使用者工期仍為零。

## 後續待確認

CSV 匯入，預計包含 ID、上階、名稱、起日、工期、前置關係及說明；實際格式需使用者確認後實作。

實際進度、基準期程、工作日曆、PDF 分頁與拖曳日期尚未排入版本。資料不做雲端同步。

## V2.1 已確認並實作

本機多專案選單、自動保存／切換／新增／刪除；舊專案遷移。
上階可選累計工期或固定工期，不增加提示句。首次建立子項依使用者是否編輯日期／工期決定預設模式。
固定期間不被子項覆寫，超期顯示具名工項與天數；支援前置起算，子項連動需明確設關係。
日期衝突採最早可行日並顯示原因。不新增工期鎖頭按鈕。
新增頂層插在選取所屬根節點的整個子樹後；清空目前專案為單層確認，不要求備份。
CSV 格式仍待另行討論。

## V2.1.1 修正

新增工項改為選取工項的同層項目，插在該子樹後；固定／累計工期共用上階圖示；PNG 文字區塊垂直置中。浮時與要徑維持 V2.1。

## V2.2.0 已確認並實作

- 新增里程碑取代切換：同層、子樹後插入，選取位置不變；網頁／PNG／箭頭日末座標一致。
- 最上階非里程碑項次旁設 stageControl 旗標；tooltip「階段性任務或任務分段控制點」，圖片輸出不顯示。
- stageControl 須為固定工期；累計轉固定需確認，關閉保留固定，轉累計或縮排下階則關閉。舊資料預設 false，本機與 JSON 持久化。
- 同一網路先前推，再把每個開啟旗標的上階完成日作為該子樹所有排程節點的最晚完成限制，沿前置關係反推，跨階段取較嚴格者。沒有旗標時沿用全案最晚完成目標。
- 上階期間由自身日期、工期、前置起算決定，不因下階超期自動延長。不建立隱含的父子前置依賴；若後項須等實際子項完成，需明確依賴子項／里程碑。
- 不另顯示階段浮時與全案浮時；0／負值標紅，負值顯示需提前天數與控制期限。各階段浮時不相加。
- 不改動已完成的 V2.1.1 同層新增、固定上階橫條、PNG 文字垂直置中與隱藏前置／浮時欄。CSV、實際進度及基準期程仍延後。
