# 自動化甘特圖｜產品規格與版本目標

更新日期：2026-09-15

## 產品定位

提供工程規劃、設計、審議及施工期程使用的輕量化甘特圖編輯器。操作方式延續 Excel 表格的直覺，但橫條位置、工期、上階彙整及要徑由系統處理。

V1 採純前端架構，不設帳號、後端或資料庫；工程資料保留於使用者目前的瀏覽器，並以 JSON 檔跨裝置備份。

## 已確定的設計決策

| 項目 | 決策 |
|---|---|
| 基本輸入 | 使用者輸入開始日期與完成日期 |
| 工期 | 系統自動計算，開始日與完成日均計入 |
| 時間單位 | V1 使用日曆日 |
| 顯示尺度 | 日、週、月、季、年 |
| 工項結構 | 多層 WBS，不限制兩層 |
| 上階日期 | 由下階工項自動彙整 |
| 要徑 | 依 CPM 自動計算，不由使用者手動指定 |
| 邏輯關係 | FS、SS、FF、SF |
| 時間間隔 | 支援正值延遲及負值提前 |
| 計畫日期 | V1 保留使用者輸入值，不自動覆寫 |
| 邏輯衝突 | 計畫日期不符合關係時提出提示 |
| 資料保存 | 瀏覽器本機儲存＋JSON 匯入匯出 |
| 發布 | GitHub Pages |

## V1 目標

1. 建立、刪除及重新排序工項。
2. 建立多層下階工項，支援縮排、取消縮排、展開及收合。
3. 輸入工項名稱、起訖日期及主要控制說明。
4. 自動計算日曆工期。
5. 上階工項自動彙整下階日期並繪製彙整橫條。
6. 切換日、週、月、季、年時間尺度。
7. 設定多個前置工項、關係類型及時間間隔。
8. 自動執行 CPM 前推、後推、總浮時及要徑判定。
9. 偵測循環關係、無效日期及計畫日期衝突。
10. 自動儲存於瀏覽器，並支援專案 JSON 匯入匯出。

## V2 目標

1. 預定進度、實際進度與完成百分比。
2. 基準期程與目前期程比較。
3. 里程碑。
4. 甘特圖前後關係箭頭。
5. 拖曳橫條調整起訖日期。
6. 工作日曆、週休與國定假日。
7. Excel 匯入與匯出。
8. PNG、PDF 成果輸出。
9. 要徑、逾期及未完成工項篩選。
10. 視實際需求評估多專案及雲端同步。

## CPM 計算約定

V1 將最下階工項視為活動，上階工項不參與網圖計算。每一活動以開始時點 `S` 與日曆工期 `D` 表示，完成時點採半開區間 `S + D`；介面顯示的完成日期則為最後一個計入工期的日曆日。

各關係轉換為活動開始時點間的限制：

- FS：`S後 ≥ S前 + D前 + lag`
- SS：`S後 ≥ S前 + lag`
- FF：`S後 ≥ S前 + D前 + lag − D後`
- SF：`S後 ≥ S前 + lag − D後`

網圖須為有向無環圖。系統以最長路徑進行前推計算，再由專案完成時點反向計算最晚時點與總浮時；總浮時為 0 的活動判定為要徑。

## V1 已知限制

- 僅計算日曆日，尚未排除週休及國定假日。
- 計畫日期與 CPM 計算日期分開，系統不會自動重新排程。
- 尚未繪製關係箭頭。
- 資料不會自動同步至其他裝置。
- 尚未直接讀取或輸出 Excel、PNG、PDF。
