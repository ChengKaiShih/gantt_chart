# 工程甘特圖工具 V2.1

為服務建議書、一般報告書與簡報製作工程期程圖。

**[開啟網頁](https://chengkaishih.github.io/gantt_chart/)**

## 使用方式

1. 新增工項或下階工項，輸入名稱、開始日期及工期（日曆天）。
2. 點「設定」加入前置關係；下方立即顯示各關係允許日期及整體排程結果。
3. 修改工期、前置工項或時間間隔，後續工項自動連動，上階日期與要徑同步更新。
4. 拖曳表頭右邊界調整欄寬，雙擊自動適配。說明文字自動換行，列高與甘特圖同步。
5. 選擇日、週、月、季、年及自動範圍／完整年度。自動範圍只保留最早至最晚工項所在時間單位，中間空檔保留。
6. 選取最下階工項後可切換為零工期里程碑（菱形）。可開關前置箭頭。
7. 使用「報告預覽」檢視圖表；選擇完整表格＋甘特圖或僅甘特圖，下載 PNG 或複製圖片貼入 Word／PowerPoint。

## 日期規則

- 一般工項：完成日＝開始日＋工期－1。週末、假日均計入；工期須為正整數。
- 直接修改完成日會反算工期。修改開始日同時設定「不得早於」限制。
- 有前置關係時依關係排程；可在關係視窗清除或設定「不得早於」。多個條件取最晚允許日期。
- 無前置關係的工項依自己的開始日期排定。
- FS＋0：前項 10/10 完成，後項 10/11 開始；FS＋1 為 10/12。
- SS＋0：同日開始；FF＋0：同日完成。SF＋0：後項完成日不得早於前項開始日。
- 正 lag 延後、負 lag 提前；SS／FF 不額外加一天。畫面會顯示實際計算日期。
- 里程碑代表當日發生的零工期事件；其 FS 後續可於事件當日開始。
- 累計工期上階僅彙整；固定工期階段可設定前置關係，也可作為子項的起算依據。CPM 摘要仍以最下階活動計算，上階履約期間不視為施工活動，期限超出另外提示。
- 循環關係當場拒絕並於關係視窗顯示原因。

## 圖片與資料保存

PNG 以 2 倍解析度獨立繪製，包含標題、圖例、完整說明文字及目前展開的工項，不受捲動位置影響。複製圖片需要瀏覽器剪貼簿權限；不支援時改下載。過大圖面會提示收合工項或改用較大尺度。

資料僅儲存在目前瀏覽器，不會傳至 GitHub。V2.1 可透過左上專案選單新增、切換及刪除本機專案。使用「備份 JSON」及「匯入 JSON」跨裝置保存。沿用 V1 儲存位置並讀取 V1 JSON；首次開啟 V2 會依現有工期與前置關係重新排程，後續編輯自動保存。

## 版本目標

- **V1（已完成）**：多層 WBS、手填起訖日期、時間尺度、關係設定、CPM、自動保存與 JSON 備份。
- **V2.0（本版）**：工期輸入、自動連動排程、即時結果與錯誤、欄寬／換行、自動時間範圍、里程碑、箭頭、報告預覽及 PNG 複製／下載。
- **V2.1（待討論）**：CSV 匯入；欄位格式另行確認。
- 實際進度、基準期程、工作日曆、拖曳日期及 PDF 分頁暫不列入本版。

## 開發與部署

純 HTML、CSS、JavaScript，無第三方瀏覽器執行依賴。`dist/` 直接保存可編輯原始碼，不是由另一份 src 建置產生。

```bash
python -m http.server 8000 --directory dist
npm test
npm run check
```

開啟 http://localhost:8000。Node.js 18 以上可執行測試；`tests/` 包含日期、前置關係、連動、循環及里程碑測試。

推送 `main` 後，GitHub Actions 將 `dist/` 部署至 GitHub Pages。Pages 的 Source 應設為 GitHub Actions。

目前未指定開源授權。

## V2.0.1 操作更新

- 工作項目與主要控制／說明均可自動換行；輸入時同步增高。
- 拖曳左側「項次」儲存格底部邊界調整列高，雙擊恢復自動列高。列高至少容納完整文字，避免裁切。
- 調整欄寬或列高時，右側橫條、里程碑及關係箭頭同步置中／定位；手動列高隨 JSON 保存並套用到 PNG。
- 新增下階工項後保留原本的上階選取，可連續新增 1.1、1.2；選取 1.1 後也可連續新增 1.1.1、1.1.2。新增頂層工項同樣保留既有選取，空白專案才選取第一筆。

## V2.0.2 操作更新

- 拖曳右側時間軸下層日期格的右邊界，可同步調整目前尺度所有格子的寬度；雙擊恢復預設。
- 日、週、月、季、年分別記住格寬，隨專案 JSON 保存。相同尺度的時間格等寬，日期在各格內依實際日數定位；橫條、箭頭與 PNG 同步調整，排程日期不變。
- PNG 下載與複製圖片移除「前置關係」及「浮時」兩欄，編輯表格仍保留。JSON 備份持續保存完整排程資料。
- 固定履約期間未納入本次調整。

## V2.1

- 左上圖示改為專案選單，支援本機新增、切換及刪除專案。新建為空白專案；原有 V1／V2 資料自動成為第一個專案。舊儲存鍵保留作為遷移前備份，新版使用獨立專案清單。
- 原「彙整」改成「累計工期／固定工期」下拉選單。自行編輯過工期或日期的工項第一次建立子項時，預設為固定工期；未自行編輯則為累計工期。舊資料無法回溯是否曾手動編輯，原上階沿用累計模式，可手動切換。
- 固定工期的起訖日期、工期可編輯，並可設定前置關係。子項超出期限時列出工項與超出天數，階段期間不被延長；固定階段以外框表示。
- 子項要隨階段開始連動，可設定階段為前置並選 SS。階層本身不會隱含建立前置關係。循環仍會被拒絕。
- 指定日期早於前置允許日期時採最早可行日期，原因顯示於工項列及關係視窗。
- 「刪除工項」移到新增下階與切換里程碑之間；「清空專案」在編輯按鈕列最右側，只提供「確定清空／取消返回」，只清空目前專案工項，保留名稱與版面設定。
- 新增最高階工項插在選取工項所屬最高階的整個子樹後，保留原選取。沒有選取時才加在末尾。
- JSON 匯入／載入範例只取代目前專案內容；其他已保存專案不受影響。JSON 匯出仍為目前專案完整備份。
- 未加入工期鎖頭選單，維持既有日期／工期操作。

驗證包含排程單元測試、舊資料遷移、本機多專案切換、清空取消／確認、刪除專案及新增位置的 DOM 互動檢查。
